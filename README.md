# LeaveFlow

A leave management app built with **ASP.NET Core Web API**, **Entity Framework Core**, **SQL Server**
and **Angular** to learn the modern .NET / Angular stack.

Employees submit leave requests; managers approve or reject them. The project covers REST API design,
JWT authentication with role-based authorization, EF Core migrations and optimistic concurrency,
Angular reactive forms and RxJS, automated tests, Docker and CI.

> Work in progress. See the learning plan in [docs/ROADMAP.md](docs/ROADMAP.md) and the daily
> progress in [docs/LOG.md](docs/LOG.md).

## Tech stack

- Backend: ASP.NET Core Web API, EF Core, SQL Server
- Frontend: Angular (standalone components, signals), RxJS
- Tests: xUnit, Moq, WebApplicationFactory, Testcontainers
- DevOps: Docker, docker compose, GitHub Actions, Azure App Service
